# 🏛️ Sistema De Projetos Governamentais
    - Um sistema para gerenciamento de projetos dentro de órgãos públicos,
      permitindo controlar etapas, responsáveis, prazos, histórico de ações 
      e comunicação interna.

- 🎯 Foco projeto: 
    - 
        - O foco é trazer transparência e organização ao ciclo de vida dos projetos governamentais.

- 🧩 Tecnologias:
  - 
      - Java + String Boot
      - Spring Boot 3.5.7
            - Spring Data JPA
            - Spring web
            - Spring Boot Starter Validation
            - Spring Boot Starter Test
      - Thymeleaf (template engine)
      - Springdoc OpenAPI (Swagger) – documentação da API REST
      - Lambok – geração automática de getters, setters e construtores
      - Oracle Database 21c (PL/SQL) – banco de dados
      - Html e css
      - Java Script

- ⚙️ Instalações:
    -
      - Java 21 ou mais atualizado
      - Java jdk-23 ou mais atualizado
      - Banco de dados: Oracle Database 21c Express Edition for Windows x64

      Instalar Oracle

      - Instalar pacote que está na pasta "Instalação do banco de 
        dados\OracleXE213.zip"
      - Se quiser uma interface gráfica para utilizar, acesse a mesma pasta e extrair 
        o zip "sqldeveloper-21". 
    [**Banco de Dados**](https://drive.google.com/drive/folders/1MLRkhHWI1EVGLzWiUHW4r4VpzhupTiy6?usp=drive_link)

- 🚀 Executando o projeto [**Site**](http://localhost:8080/)
  -
        1. Antes de rodar o projeto, defina seu usuário e senha no application.properties 
           que foi configurado no banco oracle. 
        2. Para acessar o projeto é só rodar no cmd dentro da pasta com o 
           comando: "mvn spring-boot:run" e clicar no link ou acessar localhost:8080.

- 📘 Instruções do [**Swgger**](http://localhost:8080/swagger-ui/index.html#/)
  -  
        - Para acessar o swegger é simples, com o projeto rodando acesse o link acima
