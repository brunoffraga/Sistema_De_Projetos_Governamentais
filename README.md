# Sistema De Projetos Governamentais
    - Um sistema para gerenciamento de projetos dentro de órgãos públicos, 
    permitindo controlar etapas, responsáveis, prazos, histórico de ações e comunicação interna.

- Foco projeto: 
    - 
        - O foco é trazer transparência e organização ao ciclo de vida dos projetos governamentais.

- Tecnologias:
  - 
      - Java + String Boot
      - Spring Data JPA
      - PL/SQL
      - REST API (com Swagger)

- Instalações:
    -
      - Java
      - Java jdk-23
      - Banco de dados: Oracle Database 21c Express Edition for Windows x64
      - Lambok
